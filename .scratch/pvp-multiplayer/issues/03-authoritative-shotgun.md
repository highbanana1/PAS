# 03: 权威霰弹枪命中切片

**What to build:** 让两名联网玩家使用霰弹枪时看到并接受同一组权威弹丸、世界遮挡、命中、生命格和死亡结果。

**Blocked by:** 02: 两进程建房与移动同步.

**Status:** completed

**Primary executor:** Codex

- [x] 先写一次有效开火产生 5 颗独立弹丸的失败规则测试，禁止把多颗弹丸合成一次攻击。
- [x] 弹丸按可见大小连续扫掠，并在世界与角色候选中选择最近碰撞。
- [x] 弹丸生命周期由权威时钟决定，不受任何摄像机可见性影响。
- [x] 服务器生成散射方向、速度与 shot 标识；客户端预测表现可与权威结果对应或撤销。
- [x] 分格生命继续对每一颗弹丸独立吞掉当前格外的超额伤害。
- [x] host 与 client 最终观察到相同血量、死亡和弹丸销毁结果。

验证：权威、状态副本、表现与真实双进程 ENet 测试通过；贴墙枪口遮挡、异常瞄准向量、乱序/重复数据和子进程自然退出均有回归覆盖。
