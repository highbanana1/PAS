# PvP 采用有限星星的个人撤离目标

用户选择个人撤离，而非队伍积分或击杀积分：场上同时有多颗数量有限的星星，每位玩家有一颗即可交到桌子，并绑定交付者进行撤离读秒。成功者获得个人胜利、退出战斗并观战，其余玩家继续。成功消耗该星星且本局不补充，星星因此构成有限撤离名额；死亡保留读秒复活，不等于本局淘汰。每个撤离点一次仅一位玩家使用，取消与死亡必须能撤销已交付状态；联机结算必须区分个人成功与整局结束。

追加决定：比赛开始后允许新玩家直接加入战斗。普通玩家断线时不会立即移除角色，而是预留重连时间，期间角色留在场上且仍可被攻击；保留时长、撤离读秒是否继续和期满处理仍待确认。撤离读秒达到 30 秒与致死攻击发生在同一权威结算时刻时，撤离成功优先，成功者不再产生死亡掉落或进入复活。
