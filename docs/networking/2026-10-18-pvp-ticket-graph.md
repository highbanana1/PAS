实现 frontier 当前为 06。每个任务使用自己的失败行为测试和最小实现；完成并验证后才解除下一条阻塞边。

Ticket 05 已在 `MatchAuthority` 接入星星 FREE/CARRIED/BOUND/CONSUMED 状态及地图撤离点。默认读秒 30 秒，离开返还给交付者、死亡落在死亡位置；读秒到点与同刻致命剑击并发时撤离先结算。获胜者转观战，其他人继续。本地双进程 ENet 测试验证客户端拾星交付与双方收敛，地图节点测试验证现有星星与桌子的联机自动交互及会话结束后单机入口恢复。断线保留席位和中途加入仍属于 Ticket 06。

外部 API 只接收对应 ticket 所需的代码片段、已确认规则与验收条件，不接收凭据或无关项目内容。其输出按不可信草稿处理，必须由 Codex 核对、运行测试并整合；外部 API 不直接推送仓库。
